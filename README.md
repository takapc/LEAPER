# LEAP 英単語クイズ

LEAP改訂版の英単語2,300語を、ブラウザで繰り返し学習するためのフラッシュカード型Webアプリケーションです。
同梱したJSONデータから出題し、全ユーザーの累計語数と任意のブラウザ連携をVercel FunctionsとUpstash Redisで扱います。

## 主な機能

- 全2,300語から、出題済みの単語を除外してランダム出題
- 「英語 → 日本語」のフラッシュカード
- カードのタップによる答えの表示・非表示
- カード右下のボタンから、語族・類義語・対義語と意味を一覧表示
- 英単語のスペル検索と、検索結果から選んだ単語のカード表示
- 前の問題・次の問題への移動
- Part単位の複数選択、または単語番号による詳細な範囲指定
- 「タグ」タブで品詞・多義語を選び、選択したタグをすべて満たす単語に絞り込み
- 現在の出題範囲における学習進捗の表示
- 履歴を削除しても残る、端末別と全ユーザーの累計語数の表示
- 間違えた問題のマークと、Part・詳細範囲に重ねて使えるオン／オフ式の絞り込み
- 3秒ごとに問題を進める自動再生
- ブラウザのSpeech Synthesis APIを利用した英単語の読み上げ
- JSONファイル、JSONテキスト、HTMLテーブルからの単語データのインポート
- 設定画面の期限付きコードでブラウザを連携し、ログインなしで学習状況と設定を自動同期
- 設定の管理者モードから、個人の累計語数をコマンドで変更（サーバー側パスワード認証）

## 出題範囲

| 選択肢 | 単語番号 |
| --- | ---: |
| Part 1 | 1–400 |
| Part 2 | 401–1000 |
| Part 3 | 1001–1400 |
| Part 4 | 1401–2000 |
| ＋α | 2001–2300 |

複数のPartを選択した場合は、選択したPartだけを組み合わせて出題します。詳細範囲タブでは開始番号と終了番号を直接指定できます。

「タグ」タブでは、品詞と「多義語」を組み合わせられます。選択したタグはすべて満たす必要があり、
たとえば「名詞＋他動詞」は両方の品詞を持つ単語、「名詞＋多義語」は名詞の語義を持ち、
登録された意味が2つ以上ある単語が対象です。同じ品詞の意味が複数ある単語も多義語に含みます。
「意味が3つ以上」タグでは、登録された意味が3つ以上ある単語に絞れます。
「多義語」と同時に選んだ場合も3つ以上が対象です。
Part・適用済みの詳細範囲・「間違えた問題のみ」とも組み合わせられます。
該当語がない組み合わせはメッセージを表示し、直前の出題条件とカードを保ちます。
「タグを解除」で品詞・多義語の選択だけを解除でき、範囲や間違えた問題の条件は保持します。

## データとブラウザ保存

### 標準データ

`src/data/words.json`にLEAP改訂版の全2,300語を同梱しています。アプリ起動時はこのデータを読み込みます。
各項目の形式は次のとおりです。

```json
{
  "id": 1,
  "word": "agree",
  "meanings": [
    { "partOfSpeech": "intransitive-verb", "meaning": "賛成する" },
    { "partOfSpeech": "intransitive-verb", "meaning": "意見が一致する" }
  ],
  "relatedWords": [
    {
      "word": "match",
      "meaning": "[他] ①～と調和する ②～に匹敵する",
      "type": "synonym"
    }
  ]
}
```

`relatedWords[].type`には、`word-family`（語族）、`synonym`（類義語）、`antonym`（対義語）のいずれかを指定します。

### 学習状態

- 出題済みの単語IDは`localStorage`に保存され、ページを再読み込みしても引き継がれます。
- 現在の出題範囲を一周すると、その範囲の出題済みIDだけをリセットして再出題します。範囲外の進捗は保持します。
- これまでに出題した累計語数は出題済みIDとは別に`localStorage`へ保存され、「履歴を削除」後も引き継がれます。
- 未同期の共有累計は`localStorage`へ保存し、通信復旧時に再送します。バッチIDで重複加算を防ぎます。
- 「間違えた問題」の単語IDは有効期間1年のCookieに保存されます。
- 「履歴を削除」は出題済みIDと画面内の前後移動履歴をクリアします。
- 前後移動履歴そのものはメモリ上だけに保持されるため、ページの再読み込みで消えます。

### データのインポート

画面下部の「データをインポート」から、次のデータを読み込めます。

1. JSONファイル
2. JSON形式のテキスト
3. `No. / 単語 / 意味`の3列を持つHTMLテーブル

インポートしたデータは現在の画面へ即時反映され、`localStorage`にも保存されます。ただし、現行実装では次回起動時に標準の`words.json`を読み込むため、インポート済みデータは自動復元されません。

## 共有累計語数

Vercel MarketplaceでUpstash Redisをプロジェクトへ接続し、次のサーバー専用環境変数を設定します。

- `KV_REST_API_URL`
- `KV_REST_API_TOKEN`

無料運用ではUpstashのFreeプランを使い、`autoUpgrade`を無効にしてください。クライアントは複数回の出題をまとめて同期し、既存ユーザーの端末内累計も初回アクセス時に一度だけ共有値へ加算します。

## ブラウザ間の連携（ver1.8.0）

1. 元のブラウザで「設定」→「このブラウザでコードを発行」を選びます。
2. 別のブラウザの設定にコードを入力し、「コードで連携する」を選びます。
3. 以後は自動同期します。3台目以降は連携済みブラウザから新しいコードを発行します。

アカウントの作成・ログインは不要です。コードは5分間・1回限りで、新しいコードを発行すると
古いコードは無効になります。連携後の認証情報は各ブラウザのlocalStorageに保存します。
コードや認証情報をURL・ログへ含めません。

共有するデータは、標準LEAPの出題済みID・間違いマーク・適用済みのPart/番号範囲/タグ・
品詞ヒント・間違えた問題のみの条件と、学習モード/選択したSVLレベル、累計学習語数です。
初回は履歴と間違いマークをまとめ、両方の累計を合算し、設定は発行元を引き継ぎます（ver1.9.0以降）。
たとえば100語と50語のブラウザを連携すると150語になります。解除後の再連携も両方の現在値を合算します。
連携後に新しく解いた分は合算します。受け取った累計を「みんなの累計」へ再加算しません。
前後のカード移動履歴、自動再生の実行状態、インポートした語彙データ、SVLの出題サイクルやCSVキャッシュは共有しません。
独自インポートの出題済み履歴・間違いマーク・出題条件も標準LEAPと分離します。インポート学習中の累計加算は共有します。

変更後は約1秒で送信し、表示中のブラウザは約30秒ごと、画面へ戻ったとき、通信復旧時に同期します。
「今すぐ同期」でも更新できます。通信失敗時は同じ更新番号で再送し、二重加算を防ぎます。
同時に異なる単語を学習した変更はまとめ、同じ設定を変更した場合は後からサーバーへ届いた設定を優先します。
未適用の番号入力や未確定の学習モードは送信しません。

「このブラウザの連携を解除」は確認後に接続だけを解除し、手元の学習データは残します。
ブラウザデータを消した場合は、別の連携済みブラウザからコードを発行してつなぎ直せます。
すべてのブラウザで認証情報を失うと連携を復元できません。共有データは最終利用から180日で失効します。
1グループにつき最大64件のブラウザ登録を保持します。

APIは既存の `KV_REST_API_URL` / `KV_REST_API_TOKEN` とUpstash Redisを共用します。
追加サービスや秘密鍵は不要です。`api/browser-sync.js` はPOSTのみ受け付け、入力・送信元・
ブラウザ認証情報を検証し、コード操作と同期リクエストを制限します。コードの消費・グループ更新・
再試行用の受領記録はLuaで同時に確定します。Vite単体はAPIを実行しないため、実サービスを含む
開発確認には、環境変数を設定したVercelローカル環境（`vercel dev`）を使用してください。

出題条件は連携を使わない場合も端末に保存します。間違いマークはlocalStorageを優先し、既存のCookieも読み込みます。

## 管理者モード（ver1.9.0）

`.env.example` を参考に、ローカルの `.env` に `ADMIN_PASSWORD` を設定してください。
本番ではVercelプロジェクトのサーバー用環境変数にも同じ名前で設定し、再デプロイします。
パスワードは自分で決め、実際の `.env` はGitへ追加しないでください。
`VITE_` は付けません。未設定の場合は管理者モードを利用できず、通常の学習は続けられます。
APIの実行と試行回数の制限には、既存のVercel Functions / Upstash Redisを使います。

1. 「設定」→「管理者モード」を開き、パスワードで認証します。
2. `set-total 12345` のようにコマンドを入力し、「変更内容を確認」を選びます。
3. 表示された変更前後の語数を確認して「累計を変更する」を選びます。

`set-total 数値` は「あなたの累計」を0以上の整数に変更します。減らす変更・0への変更も可能です。
連携中はグループの個人累計を変更し、ほかのブラウザにも自動同期します。未連携ならそのブラウザだけに反映します。
**コマンドによる変更分を「みんなの累計」に加算・減算することはありません。**
変更後に実際に学習した分は通常どおり加算します。履歴・間違いマーク・出題条件は保持します。

認証は15分間有効で、認証情報はメモリ上だけに保持します。設定を閉じると再認証が必要です。
連携中の変更は、グループ・ブラウザ・同期番号・指定語数に限定した署名付きの許可を保存して送信します。
通信失敗・再読み込み後も同じ変更を再送し、後から学習した分を再試行で上書きしません。
パスワード変更は既存の管理者認証と未確定の許可を無効にします。
この機能は管理用の画面であり、通常の学習やブラウザ連携に管理者認証は不要です。

## アクセス解析（Vercel Web Analytics）

`@vercel/analytics/react` の `Analytics` をアプリ全体で1回読み込み、ページビューを計測します。
Vercelの対象プロジェクトで「Analytics」→「Enable」を選び、この変更を含むデプロイを公開してください。
公開サイトへアクセスすると、その後の訪問数・ページビュー・参照元などを同じ画面で確認できます。
有効化・導入より前のアクセスはさかのぼって取得できません。追加の環境変数は不要です。

開発モードでは実際のアクセスを集計しません。学習語数・間違いマーク・連携情報・管理者コマンドを
カスタムイベントとして送る処理も追加していません。計測スクリプトを取得できない場合も学習は継続できます。

## ライセンス・データ出典

このプロジェクトは教育目的で作成されています。単語データの出典は「受かる英語 - LEAP 改訂版 単語一覧」です。
関連語の語彙関係は、Princeton WordNetを基にOpen English WordNetチームがCC BY 4.0で提供するOpen English WordNetを参照しています。LEAPに未収録の関連語の日本語表現にはJapanese Wordnet 2.0（CC BY 4.0）を参照しています。

見出し語の `meanings` は `{ partOfSpeech, meaning }` の配列です。一つの語義ごとに要素を分け、
丸数字は保存しません。用法注記は各 `meaning` の文字列に保持します。品詞の値は
`src/utils/meanings.js` の `PART_OF_SPEECH_TAGS` を参照してください。
旧形式の `meaning` 文字列・品詞単位の配列もインポート時・保存データの読み込み時に変換します。
品詞の記載がないインポートデータでは `partOfSpeech` は空文字列です。
関連語の `meaning` と `partsOfSpeech` は従来の形式を維持します。

### SVL12000（ベータ）— ver1.4.0

右上の「設定」から LEAP / SVL12000（ベータ）を切り替え、LV01〜LV12を
1レベルずつ選択できます。SVLは単語と意味、答えの表示、前後の問題移動だけの
シンプルな学習画面です。品詞ヒント、関連語、発音、自動再生、検索、LEAPの範囲指定は表示しません。
モード・レベルの設定は端末に保存します。切り替えると問題の移動履歴をリセットします。
LEAPの出題済み履歴・間違いマークは保持し、SVLの問題IDと混在させません。
新しくランダム出題したSVLの問題も端末内累計と共有累計に1語加算し、履歴移動は加算しません。
SVLの出題済みサイクルは現在のレベルの学習中に保持します。

データ出典: [kim0051/word-levels-db の level-csv](https://github.com/kim0051/word-levels-db/tree/master/level-csv)。
選択したレベルのCSVのみを `raw.githubusercontent.com` からブラウザで取得・解析します。
12,000語のJSON、CSV、SQLiteファイルを本プロジェクトやビルド成果物へ追加する方式ではありません。
追加バックエンドやAPIキーは不要です。ブラウザ内メモリと24時間有効のsessionStorageを
キャッシュに使用し、保存不可の場合はメモリのみで動作します。タブを閉じるとセッションの
キャッシュは失われます。未取得レベルは通信必須です。取得失敗時は再試行と設定変更ができます。
15秒のタイムアウトを設け、同一レベルの並行リクエストをまとめます。
外部配信停止・CORS変更・上流CSVの形式変更に影響を受けるため、試験機能として提供します。

2026-09-07時点で上流リポジトリのREADMEとルートを確認しましたが、明示的なライセンスは
見つかっていません。出典の表示は利用許諾を意味しません。本変更は外部CSVの読み込み機能のみを
追加し、元データの複製・再配布は行いません。
